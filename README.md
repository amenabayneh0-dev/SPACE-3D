# SPACE 3D

An interactive 3D space exploration website built with React and Three.js (single-file `index.html`).

## Features
- Cinematic hero with a procedural planet, atmosphere and starfield
- Interactive Solar System Explorer (drag, zoom, pause, speed, select planets)
- Universe Mode: Alpha Centauri, nebula, galaxy, black hole, fictional alien planet generator
- Black hole shader inspired by NASA SVS 13326 and 14619 (Schwarzschild light paths, flat disk, Doppler beaming)
- Missions, settings (graphics quality, reduced motion, sound)

## Run
Open `index.html` in a modern browser (needs internet for the React and Three.js CDN scripts).

## Notes
Sizes, distances and many visuals are simplified. Illustrative and fictional objects are labeled as such.
